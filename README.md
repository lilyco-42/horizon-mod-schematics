# horizon-mod-schematics (`schematics` v2.0.1)

Standalone **Horizon** native mod for Litematica-style 3D schematic projection, material list HUD, and live hot-switching.

## Build & Install
```bash
horizon-launcher native-build \
  --version nightly-2026-11-20-0a875da \
  --trust-native-code .
```

Part of the [lilyco-horizon](https://github.com/lilyco-42/lilyco-horizon) ecosystem.
